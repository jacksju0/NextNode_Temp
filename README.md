# NextNode_Temp

모두의연구소 LMS의 "내일노드 - 백엔드 입문" 스텝 10개를 **하나의 자립형 HTML 파일**로 병합한 문서입니다.

## 바로 보기

<https://jacksju0.github.io/NextNode_Temp/>

> GitHub Pages가 아직 켜져 있지 않으면 위 링크는 404가 납니다.
> `Settings` → `Pages` → `Source: Deploy from a branch` → `Branch: main` / `/ (root)` → `Save` 로 활성화하세요.

## 파일

| 파일 | 설명 |
|---|---|
| [`내일노드_통합.html`](%EB%82%B4%EC%9D%BC%EB%85%B8%EB%93%9C_%ED%86%B5%ED%95%A9.html) | 본문 전체 (약 5MB). CSS·이미지·폰트를 모두 인라인한 단일 파일 |
| `index.html` | 위 파일로 보내는 리다이렉트 (Pages 루트용) |

## 특징

- 외부 의존성 **0** — `<link>` / `<script>` / 외부 이미지 / 외부 폰트 요청이 전혀 없습니다
- 이미지 10장은 base64 data URI, 본문 폰트(pretendard 가변)도 인라인
- 스텝 10개 목차 네비게이션, 스텝별 원본 URL 표기, 인쇄 시 스텝 단위 페이지 분리

## 주의

- GitHub의 파일 미리보기는 5MB HTML을 렌더링하지 않습니다. 반드시 위 Pages 링크로 열어야 화면이 보입니다.
